# NaiWaPixel

> 奶蛙像素 · 一只会笑的奶蛙 —— 单文件、零依赖、自带内容安全锁的交互式动画页。

> **GitHub 仓库 Description（一句话）：**
> `一只会笑的奶蛙 · 单文件零依赖 HTML 动画 · 即将支持 GIF / MP4 像素重组`

## 项目简介

奶蛙是一个**完全自包含**的交互式网页：整页（美术、音效、动画逻辑）全部内联进一个 `index.html`，不依赖任何外部资源、不需要构建服务器。双击即可打开，丢到任意静态托管（GitHub Pages / Vercel / 对象存储）就能跑。

页面以一只"奶蛙"为主角，包含开场降临、大笑等动画与音效，是一个轻量、可分享的创意小页。

## 特性

- 🐸 **单文件交付**：所有美术资源（webp 抠图、jpg 原图）与音效（mp3）以 base64 内联，整页即一个约 435KB 的 `index.html`。
- 🔒 **内容安全锁（CSP）**：构建时为每个内联 `<script>` 计算 sha256 并写入 CSP 白名单。任何对脚本字节的篡改都会让浏览器拒绝执行、页面当场白屏——既是防护，也是"是否被改过"的直观自检。
- 🧩 **可复现构建**：`build.js` 从模板 + 素材重新生成成品，脏数据不会进仓库。
- 📦 **零运行时依赖**：纯 HTML / CSS / JS，无框架、无 npm 运行时。

## 本地构建

```bash
node build.js
# 读取 index_template.html + _art/ + audio/，输出自包含的 index.html
```

仅构建期需要 Node.js，运行期不需要任何依赖。

## 目录结构

```
.
├── index.html            # 构建产物（自包含，部署用这个）
├── index_template.html   # 页面模板（含 __占位符__）
├── build.js              # 构建脚本：内联资源 + 注入 CSP
├── _art/                 # 美术素材（webp 抠图、原图等）
├── audio/                # 音效素材（laugh.mp3 等）
├── .nojekyll             # 禁用 GitHub Pages 的 Jekyll，保护 CSP 不被改写
└── .gitignore
```

## 部署（GitHub Pages）

1. 把仓库推到 GitHub；
2. `Settings → Pages → Source` 选择分支（如 `main`）+ `/ (root)`；
3. **务必保留根目录的 `.nojekyll`**：否则 Jekyll 会重整 HTML，导致 CSP 的 sha256 与脚本字节不匹配 → 页面白屏。
4. 首次部署可能需要几分钟生效。
